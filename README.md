# Ch-Na-Mu

Professional digital profile for **Christine Nanyombi Mubiru, CHRA**.

## Features
- Executive-style responsive profile page
- Custom loader with printed name animation
- Direct actions: call, WhatsApp, email, LinkedIn, save contact, share
- About, expertise, experience, institution, and contact sections
- No photo dependency (uses premium initials placeholder for now)

## Files
- `index.html`
- `styles.css`
- `script.js`

## Run locally
Open `index.html` in a browser.

## Deploy
This project can be deployed easily to GitHub Pages, Netlify, or Vercel.
